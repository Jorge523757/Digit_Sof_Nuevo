# ⚡ RECUPERACIÓN RÁPIDA DE CONTRASEÑA - GUÍA RÁPIDA

## 🎯 ¿Qué se hizo?

Se optimizó el sistema para que los correos de recuperación de contraseña lleguen **MÁS RÁPIDO** (en menos de 1 minuto).

## 🚀 Inicio Rápido

### 1. Ejecuta el configurador:
```bash
CONFIGURAR_EMAIL_GMAIL.bat
```

### 2. Ingresa tus datos:
- Email de Gmail
- Contraseña de aplicación (no tu contraseña normal)

### 3. El script hace el resto:
- Prueba la conexión
- Crea el archivo .env
- Envía email de prueba (opcional)

### 4. Reinicia Django y ¡listo! 🎉

## 🔑 Contraseña de Aplicación

1. Ve a: https://myaccount.google.com/apppasswords
2. Activa verificación en dos pasos
3. Genera contraseña para "Correo"
4. Cópiala y úsala en el script
