🐳 INSTRUCCIONES PARA USAR DOCKER
════════════════════════════════════════════════════════════════════════════════

PASO 1: INICIAR DOCKER DESKTOP
────────────────────────────────────────────────────────────────────────────────
Antes de continuar, asegúrate de que Docker Desktop esté ejecutándose:
• Abre Docker Desktop desde el menú de inicio
• Espera a que aparezca el ícono de Docker en la bandeja del sistema
• Verifica que el ícono no tenga ningún error

PASO 2: LEVANTAR LOS CONTENEDORES
────────────────────────────────────────────────────────────────────────────────
Ejecuta el siguiente comando en la terminal:

    docker-compose up -d

O usa el archivo por lotes:

    DOCKERIZAR_AHORA.bat

PASO 3: CREAR SUPERUSUARIO
────────────────────────────────────────────────────────────────────────────────
Una vez que los contenedores estén corriendo, crea un superusuario con:

    docker-compose exec web python manage.py createsuperuser

O usa el archivo por lotes:

    CREAR_SUPERUSER_DOCKER.bat

PASO 4: ACCEDER A LA APLICACIÓN
────────────────────────────────────────────────────────────────────────────────
• Aplicación web: http://localhost:8000
• Panel de administración: http://localhost:8000/admin

🔧 SOLUCIÓN DE PROBLEMAS
════════════════════════════════════════════════════════════════════════════════

❌ ERROR: "Cannot connect to Docker daemon"
────────────────────────────────────────────────────────────────────────────────
CAUSA: Docker Desktop no está ejecutándose
SOLUCIÓN:
    1. Abre Docker Desktop
    2. Espera a que se inicie completamente
    3. Intenta nuevamente

❌ ERROR: "Port 8000 is already in use"
────────────────────────────────────────────────────────────────────────────────
CAUSA: El puerto 8000 ya está siendo usado
SOLUCIÓN:
    1. Detén cualquier servidor Django local: Ctrl+C
    2. O cambia el puerto en docker-compose.yml

❌ ERROR: Localhost no abre
────────────────────────────────────────────────────────────────────────────────
CAUSA: Los contenedores no están corriendo o hay un error
SOLUCIÓN:
    1. Verifica que los contenedores estén corriendo:
       docker-compose ps

    2. Ve los logs para ver errores:
       docker-compose logs web

    3. Reinicia los contenedores:
       docker-compose restart
