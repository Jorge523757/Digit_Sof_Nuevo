❌ SOLUCIÓN DE PROBLEMAS

   • Google OAuth no funciona:
     → python LIMPIAR_GOOGLE_OAUTH.py

   • No aparece reCAPTCHA:
     → pip install django-recaptcha
     → Reiniciar servidor

   • No veo el código de recuperación:
     → Está en la consola del servidor, NO en tu email

   • Error al hacer git push:
     → Lee: SOLUCION_GIT_SECRETOS.md
